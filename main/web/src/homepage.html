CSV Datalog (SD):
Engine-On Voltage:
13.0V
Engine-running detection for CSV auto start/stop. Logs only when charging (alternator) voltage is reached. Separate from Sleep Voltage.
Require Engine Running:
On: CSV logs only while the ECU is answering (engine running) and closes the file per drive. Off: logs whenever powered (bench use). A trip started from the Console always logs regardless of this setting.
Polling Rate (Hz):
Auto logs at the fastest rate your PID list allows: the device measures the real polling round-trip over all PIDs and matches the row rate to it (1–100 Hz), so every row carries fresh polled values — no duplicates, no gaps. Broadcast channels update faster than that and are always fresh at any rate.
Low-Voltage Behavior:
Uses Sleep Voltage, unless “Custom Voltage” is selected. “Pause all polling” stops the poller entirely. “Pause PID polling only” stops PID requests, but CAN filters/monitoring stay active. Applies to the Legacy AutoPID protocol; the Datalogger protocol handles engine-off quiesce on its own.
PID Polling Min Voltage: 12.0V
Low-Voltage Protection Warning
It is recommended to keep this enabled. Polling the ECU when the battery voltage is low can increase battery drain while the vehicle is parked.
PID Polling Inactive
The current protocol does not poll PIDs, so nothing can be recorded. Restore the Datalogger (poll_log) protocol by downloading the configuration on the System page, setting "protocol" to "poll_log", and uploading it back.
Sensor Set
Saves every sensor below — polled, broadcast and calculated — to one readable .yaml file you can keep as a backup, edit by hand, share, or load onto another adapter. It records exactly what you see here: Mode, PID — or address and read size for a Mode 23 memory read — and the standard A/B/C formula. Sensors only: no Wi-Fi credentials and no device settings. Importing replaces the tables below for review; nothing reaches the device until you press Store.
Polled PIDs
Sample Rate skips a PID on all but every Nth polling sweep, freeing bus time for the fast channels. Estimates are scaled from the currently measured sweep and update live as you edit — slowing channels down shortens the sweep, so every other channel speeds up too.

Firmware Update
Firmware updates are available on GitHub. Download the latest release's OTA app image and upload it below. Instructions are available here.
WiCAN adapter recovery — this device only, NOT the car's ECU: a failed update cannot permanently brick this adapter. Hold the hardware button for 5 seconds to start the Recovery AP, then re-upload firmware on this page. The NC Flash port 35001 stays always on. Recovering the car's ECU after an interrupted flash is a separate procedure done from NC Flash on the PC — never from this page.
