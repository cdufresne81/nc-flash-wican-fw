# v1.28.0-beta.1 - Dynamic Flash rewrites only what changed (beta)

A test build. One new feature: with NC Flash, the adapter can flash an ECU by **rewriting only the parts of the ROM that changed**, which is about 2.5 times faster for a typical tune change.

⚠️ **This is a beta.** It passed a bench test on a real ECU (results below), but it has not been used on cars yet.

⚠️ **You need NC Flash v2.25.0-beta.1 or newer, with "Dynamic Flash: use the new block-compare method" turned on** (Settings > ECU > Flashing; it is off by default). Without it nothing changes: NC Flash flashes exactly as before, and older NC Flash versions work as before with this firmware.

## What changed

Until now, a Dynamic Flash over the WiCAN still had to send a large part of the ROM and rewrite it.

Now NC Flash sends the adapter one package and the adapter does the rest by itself:

- It asks the ECU for a checksum of every block of its memory and compares it with your ROM.
- It rewrites **only the blocks that differ**, sent compressed.
- It checks every block against the ECU before the ECU is allowed to start again.

Because the adapter runs the whole flash itself, a Wi-Fi hiccup or NC Flash closing in the middle no longer interrupts it: on the bench, NC Flash was killed mid-flash and the adapter finished and verified the flash on its own.

## Bench results (NC2 ECU, same test ROMs, connect and checks included)

| Change | Before (SD-staged) | Now |
|---|---|---|
| One block | 16.8 s | 10.5 s |
| Three blocks (a typical tune change) | 55.5 s | 21.3 s |

## Safety

- The adapter never touches the ECU's boot code. The part that makes the ECU start is erased first and written last, so if anything goes wrong the ECU waits in recovery mode, and a normal full flash from NC Flash brings it back.
- Before anything is erased, the adapter checks the package, the flash program it uploaded into the ECU, the link, and that the ROM is for this ECU's generation (NC1 vs NC2).
- If a flash is interrupted, NC Flash recognises it at the next connect and offers to finish it.
- While a flash runs, the adapter refuses logging, reboots, updates and settings changes, as it already does for a normal flash.

## Not tested yet

- Use on cars.
- Finishing a flash after the adapter itself lost power mid-flash (covered by automated tests only; a normal full flash recovers the ECU either way).
- NC1 ECUs: NC Flash does not offer this method on them yet.
