# v1.27.0 - Start Logging in NC Flash logs the channels you ticked

One new feature. NC Flash can now hand the adapter a channel list **for one logging run**, without touching the list the adapter logs on its own.

⚠️ **This has not been run on a real adapter yet.** It builds, and its rules are covered by automated tests on a PC, but nobody has tried it on hardware. The checks still to do are listed at the bottom. Treat this release as a test build until they are done.

⚠️ **You need NC Flash v2.24.0-beta.17 or newer to use it.** Older versions work exactly as before - they just do not know about the new feature.

## The problem

With a Tactrix or OBDX cable, logging in NC Flash is simple: tick the channels you want, press **Start Logging**.

With the WiCAN there was an extra step, **Send Channels to WiCAN**, and it had three ways to bite:

- It **overwrote the adapter's own list** - the one it logs by itself on every drive. Tick three channels for a quick test, and your next commute recorded three channels.
- If a trip was already being recorded, the new list was **held back until the engine was switched off**.
- If NC Flash crashed or the laptop went to sleep, the adapter **kept the changed list forever**.

## What changed

The adapter now accepts a **temporary** channel list.

- It lives in the adapter's memory only. The saved list is **never written**.
- It takes over straight away. If a trip is being recorded, that file is closed and a new one starts with the new channels - no file ever mixes two sets of columns.
- It ends when you press **Stop**, and the adapter goes back to its saved list.
- It also ends **by itself** if NC Flash disappears (about 30 seconds without hearing from it), when the adapter goes to sleep, and at a reboot. You cannot be left with a list you did not save.

While a temporary list is in use the adapter records whenever the engine computer answers, the same as pressing Start on its own web page. When the list ends, recording goes back to however you had it set.

## Safety

The adapter also flashes ECUs, so this was built to stay out of the way of that.

- A temporary list **cannot be started while NC Flash is reading, writing or talking to the ECU**, and it never changes any of the locks that protect a flash.
- A list may only contain **read requests** (OBD modes 01, 22 and 23). Anything else is refused before it is stored, with a message saying why.
- A list is limited to 128 channels and 64 KB.
- If the new list cannot be loaded, the adapter keeps logging the list it had.

## What you will see

- **Event log:** one line when NC Flash starts logging its own list, one when it ends, with the reason (stopped, NC Flash stopped answering, going to sleep).
- **Logger page:** if you press Store while NC Flash is logging its own list, the page says the saved list will take effect when that ends. Your save is not lost.
- **Trip files:** a file closed for a list change shows the reason `channel_list` in the event log.

## One thing to know

The adapter can only switch lists if its own datalogger is running, and that needs **at least one polled channel in its saved list**. The stock list has plenty. If you emptied it, NC Flash will tell you to add one channel on the adapter's Logger page and reboot.

## Not yet tested on hardware

None of the following has been run on a real adapter and engine computer:

- Start Logging with the engine off: one new trip file, with exactly the ticked channels.
- Start Logging while a trip is being recorded: the old file closes, a new one opens, no mixed columns.
- Stop: the adapter goes back to its saved list, and the saved file is unchanged.
- Kill NC Flash mid-run: the adapter goes back to its saved list by itself within about half a minute.
- Stop logging, then start an ECU session straight away: no stray request reaches the ECU.
- Let the adapter go to sleep mid-run: it wakes on its saved list.
- A normal ECU read and a normal flash, with no logging involved, still work as before.

The full checklist is in `docs/internals/datalog_session.md`.

## Honest notes

**Starting a run during a drive splits the drive into two files.** That is deliberate - one file, one set of columns.

**If the trip file will not close, the list change waits for the engine to stop.** This should not happen with a healthy SD card. The adapter writes a warning to its event log when it does.

**The list you save on the adapter's own Logger page is not checked for read-only requests.** It never was. Only the temporary list from NC Flash is.

## Install

**Over Wi-Fi (recommended):** open the device page, go to **System > Update Firmware**, upload `wican-fw_obd_pro_v1_27_0.bin`.

**Over USB (serial):** `bootloader.bin` at `0x0`, `partition-table.bin` at `0x8000`, `ota_data_initial.bin` at `0xd000`, `wican-fw_obd_pro_v1_27_0.bin` at `0x10000`.
